# PromptGenerator 配布ページ

AI画像生成用プロンプト管理Chrome拡張機能の配布ページです。

## 🎯 このページについて

このページは **PromptGenerator Chrome Extension** の公式配布サイトです。  
最新版のダウンロード、インストール手順、使い方ガイドを提供しています。

## 📦 ダウンロード

### 最新版
- **[PromptGenerator.zip をダウンロード](downloads/PromptGenerator.zip)**
- バージョン: v1.0.0
- 更新日: 2025-07-31

### 過去のバージョン
- 履歴付きダウンロードファイルも利用可能です

## 🚀 クイックスタート

1. **ダウンロード**: 上記リンクからzipファイルを取得
2. **展開**: zipファイルを適当な場所に展開
3. **インストール**: Chrome拡張機能として読み込み
4. **使用開始**: ツールバーのアイコンをクリック

詳細なインストール手順は [チュートリアル](tutorial/index.html) をご覧ください。

## 📚 主な機能

- 🔍 **検索機能**: キーワード・カテゴリ検索でプロンプト要素を素早く発見
- ✏️ **編集機能**: プロンプト要素の個別編集・重み付け調整
- 💾 **スロット管理**: 複数プロンプトの保存・切り替え（Ctrl+1〜9）
- 📖 **辞書機能**: オリジナル辞書の作成・CSV入出力対応
- 🎯 **自動生成**: 連続Generate・要素抽出モード搭載
- 🌐 **マルチサービス対応**: NovelAI、Stable Diffusion、ComfyUI等
