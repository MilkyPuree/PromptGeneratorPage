⚡ クイックリファレンス

🎨 よく使う組み合わせ

  • 美少女イラスト: 検索タブ → 編集タブ → 翻訳
  • 背景付きシーン: スロット結合 → Generate
  • オリジナル要素: 辞書タブ → お気に入り登録

⌨️ 便利なショートカット

  • Alt + G 拡張機能を開く
  • Ctrl + Enter 翻訳実行
  • Ctrl + D 要素削除
  • Ctrl + Shift + S 辞書に保存
